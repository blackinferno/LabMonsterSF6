Lab Monster SF6 - Usage Guide

Definitive combo management tool for combo authoring, importing/exporting, safe data management, and frame-data reference.

Frame Data

Frame Data Table

  • A copy of the latest frame data table on the official website. Same data, with key values color-coded.

Version Switching

  • You can switch to older frame data tables (as far back as 2025.11.13 update).

Version Comparison

  • You can compare the frame data table with other versions.
  • Changed cells will be highlighted.
  • You can see exact changes in a tooltip by hovering over a highlighted cell.

Combo List

Combo Authoring

  • Per-character and per-control-mode combo table (Classic / Modern).
  • Comprehensive fields for conditions, damage variants, resources, carry, and post-combo state.
  • Multiline notes field for setup details and other memos.
  • Tag support for labeling routes and quick filtering.
  • (Beta) Auto-generated damage inputs.

Editing / Maintenance Tools

  • Row operations: create, duplicate, delete, and strict dedupe.
  • Often used right-click context menu for quick access.
  • Often used keyboard shortcuts (ex. Ctrl+C, Ctrl+V, Ctrl+Z) for efficient workflow.
  • Sortable headers/subheaders for quick data review.
  • Auto-generated button icons from command notation.
  • Combo Details popup with frame meter and per-starter stats.

View / Workflow Controls

  • Header context menu of hiding/showing columns.
  • Preset column views: FULL, BASIC, SIMPLE, and CUSTOM.
  • Toggle visibility of Frame Meter / Buttons / Notes rows.
  • Collapsible lower input section for larger table workspace.

Search / Filter

  • Sorting and filtering via header context menu for quick data review.
  • Quick search for broad text/value lookup.
  • Advanced Search for field-scoped and range-based filtering.

Compare combos

  • Right-click one or more selected rows and choose Add to compare to queue combos in the compare tray at the bottom of the page.
  • The tray shows Compare (n/4). You can queue up to four combos at once.
  • Click Compare to open a side-by-side modal: command, buttons, notes, tags, game version, and the main combo fields are shown in one table.
  • Use Remove from compare on a column header to drop one combo, or Clear list to empty the tray.
  • You need at least two combos in the tray before Compare is enabled.
  • The compare tray is hidden while viewing Frame Data.

Input / Device Support

  • Manual command entry, quick-input icons, and customizable hotkeys.
  • Keyboard / PS / Xbox(XInput) / D-Input display support.

Import / Export

  • Import from .xlsx and .json (template-compatible).
  • Export to .xlsx, .html, and .json for backup or sharing.
  • Supports current context and all-character batch workflows.

Automation (Beta)

  • Auto-calculation and auto-fill support for damages, distance, and other data.
  • Automatically change command and buttons based on the selected control mode.

Combo Tree

Overview

  • The combo tree visualizes routes for the current character and Classic / Modern combo list as a branching chart.
  • Branches follow your command notation; ordering along the vertical rail can follow D Gauge requirements or Damage totals.

Layout and controls

  • The portrait selector and Classic / Modern tabs match the combo list (same saved data).
  • D Gauge / Damage switches how the vertical rail sorts branches.
  • Refresh rebuilds the tree from the current (filtered) combo rows.
  • Expand All / Collapse All open or close every subtree; the counter shows how many combos are placed in the chart.

Filters

  • Pill chips open filters for Distance, Position, Counter, BO/Stun, and Special Conditions; the inline filter groups under the header use the same filter state.
  • Choose values, then Apply (or Clear) so only matching combos are included when the tree is built.

Tree interaction

  • Click a branch box or a combo leaf to select it; the right-hand detail pane shows fields for that combo.
  • Click empty space in the tree scroll area to clear the selection.
  • Right-click a branch or leaf for Add to compare, Expand subtree / Collapse subtree, Add combo from this path, and Delete child combos (when applicable).

Detail pane

  • Combo Details opens the same full modal as on the combo list (frame meter, stats, media, etc.).
  • Auto Input and Overwrite follow the combo list beta automation behavior when editing from the tree.

Analysis (Planned)

Report

  • Report on various metrics based on entered combos.
  • Ex. Expected damage per starter.

Function-Based Workflows

Frame Data Compare

What It Does

  • Loads frame data by version for the selected character and control mode.
  • Highlights changed cells between two versions and shows exact value deltas in a tooltip.

How To Do It

  1. Select character and mode.
  2. Choose the base version from the Version dropdown.
  3. Click Compare, choose a target version, then apply comparison.
  4. Hover highlighted cells to inspect exact before/after values.

Specific Uses

  • Patch impact review before updating combo assumptions.
  • Verifying whether route stability changed due to startup/recovery/frame-advantage updates.
  • Preparing per-version notes for your own matchup docs.

Combo Entry

What It Does

  • Creates and edits combo rows for each character and control mode.
  • Converts command text into button icons automatically.
  • Supports multiline notes for setup details and route conditions.

How To Do It

  1. Select character from the portrait selector and click the desired control mode.
  2. Click Auto Input if you want the tool to generate damage and other fields (Beta function). This will not overwrite manually input fields.
  3. Click Overwrite if you want to allow the auto input to overwrite manually input fields.
  4. Enter route notation in Command using quick input/hotkeys (or copy & paste).
  5. Fill required condition fields and numeric result fields.
  6. Add more specific setup or other details in Notes where needed.

Specific Uses

  • Building practical match combos with explicit start conditions.
  • Maintaining training-mode tested damage/carry/resource outcomes.
  • Documenting route variants (counter hit, punish counter, CA state, etc.).
  • Notation requirements are summarized in Notations Used.

Combo Details

What It Does

  • Opens a detailed view with frame meter, command edit, notes, URL/video, and stats.
  • Shows same starter and D gauge averages, ranks, and top combo links for quick comparison.

How To Do It

  1. Double-click a combo row or open Combo Details from the right-click menu.
  2. Edit the command or notes and click Save to overwrite the row.
  3. Paste a video URL to preview embedded footage in the modal.

Specific Uses

  • Review routes with frame meter and button icons in one view.
  • Compare same starter and same D gauge averages and top combos without leaving the popup.

Combo Compare

What It Does

  • Opens a side-by-side modal comparing two to four combos from the current character and control mode.
  • Lists command, notes, tags, version, and the main numeric fields in one table for quick scanning.

How To Do It

  1. Select one or more rows, right-click, and choose Add to compare.
  2. Watch the bottom tray for Compare (n/4); add up to four combos total.
  3. Click Compare when at least two combos are queued to open the modal.
  4. Use Remove from compare on a column header or Clear list to reset the tray.

Specific Uses

  • Compare damage and resource costs across similar starters.
  • Review multiple route notes without switching rows in the main table.
  • The compare tray is unavailable on the Frame Data tab.

Combo Tree

What It Does

  • Builds a branching chart from the current combo list for the selected character and Classic or Modern mode.
  • Reuses the same filters as the combo list and shows a detail pane for the selected branch or combo.

How To Do It

  1. Click COMBO TREE in the site header to open the tree view.
  2. Choose character and Classic or Modern; optional: use pill filters and inline filter groups, then Apply.
  3. Switch D Gauge or Damage to change vertical ordering; use Refresh after edits, Expand All / Collapse All for navigation.
  4. Click a branch or leaf to load the right pane; right-click for Add to compare, subtree actions, Add combo from this path, or Delete child combos when applicable.

Specific Uses

  • Scan extensions from a starter and spot higher-damage branches.
  • Edit fields in the detail pane or open Combo Details for the full modal.

Table Control (Rows / Columns / Sorting)

What It Does

  • Controls table density and focus using row toggles and column presets.
  • Supports strict duplicate detection and deletion of combos for the current character.
  • Provides sortable headers/subheaders for quick ordering analysis.

How To Do It

  1. Use Create, Duplicate, Delete, and Dedupe for row operations.
  2. Use shortcuts (Ctrl+C, Ctrl+V, Ctrl+Z, etc.) for quick row operations.
  3. Use FULL, BASIC, SIMPLE, or CUSTOM for column visibility.
  4. Header context menu can also be used for hiding/showing columns.
  5. Toggle Frame Meter / Buttons / Notes row visibility as needed.
  6. Click any sortable header/subheader to order the dataset.

Specific Uses

  • Use right-click context menu for quick access to these row operations.
  • Use BASIC/SIMPLE for quick reviews, FULL for in depth analysis.
  • Run Dedupe before sharing/exporting to remove exact duplicates.
  • Click the Close button below the table to collapse the lower input section when you need more table workspace.

Shortcuts

What It Does

  • Commonly used shortcuts are available for efficient workflow.
  • These shortcuts can be used in conjunction with the right-click context menu.
  • A full list of available shortcuts is provided below.

Shortcuts

  • Ctrl + C: Copy selected rows
  • Ctrl + V: Paste copied rows
  • Ctrl + X: Cut selected rows
  • Ctrl + Z: Undo edits
  • Ctrl + Y: Redo edits
  • Ctrl + H: Opens Replace popup
  • Ctrl + F: Jumps cursor to main search bar for quick lookup

Search / Advanced Filter

What It Does

  • Filtering in the header context menu allow text based and numerical filtering.
  • Search performs quick text/value lookup across standard searchable fields.
  • ADVANCED SEARCH filters by selected fields, flags, and numeric ranges.

How To Do It

  1. Use the filtering in the header context menu for column-level lookup.
  2. Use the main search bar for broad lookup.
  3. Open ADVANCED SEARCH for field-scoped and range-based filtering.
  4. Set exact/min/max values and options, then apply filter.
  5. Reset filters when starting a new review pass.

Specific Uses

  • Find lethal routes by minimum damage threshold and specific conditions.
  • Filter routes by BO/Counter state, resource thresholds, or character restrictions.
  • Target post-combo states for oki planning and consistency checks.
  • Field meanings are documented in Explanation of Fields.

Importing

What It Does

  • Imports combo data from .xlsx and .json.
  • Supports current-context export and all-character batch export flows.
  • Allows mapping of external data fields to internal fields for non-template import files.
  • Allows notation conversion from external formats with different command syntax rules. Additional notation rules can be added as needed for specific import sources.

How To Do It

  1. Click Import and select a compatible file.
  2. Check the character(s) you want to import data for and click Import.
  3. If the files is not a template, map external fields to internal fields.
  4. Ignore, delete, or replace the unrecognized notations by entering the LM notation and click Apply.

Specific Uses

  • For importing your existing combos list from spreadsheets.
  • For importing combo lists from other LM users.
  • If import fails, check sheet names/headers against templates. (Templates are stored in the Templates folder)

Exporting

What It Does

  • Exports in .xlsx, .html, and .json for backup or sharing.
  • Supports exporting current character and all-character batch export flows.
  • Allows selection of all fields or only currently visible fields for export.

How To Do It

  1. Click Export, choose format and scope options.
  2. Select whether to export all fields or currently visible fields.
  3. Validate output and run dedupe beforehand when needed.

Specific Uses

  • .json: best for backup/restore and migration.
  • .xlsx: best for spreadsheet workflows and offline review.
  • .html: best for read-only sharing and visual presentation.

Data Management / Recovery

What It Does

  • Combo data is stored in browser localStorage by character/mode context.
  • Automatically loads saved context when switching character.

How To Do It

  1. Use normal editing workflow; data is persisted automatically.
  2. Export backups before major cleanup, importing, etc.
  3. If UI becomes inconsistent, run hard refresh (Ctrl+F5).

Specific Uses

  • Recover from accidental edits by importing recent JSON/XLSX backup.
  • Maintain stable snapshots before large imports or dedupe passes.
  • Check UPDATE LOG in INFORMATION when behavior changes between releases.

Symbols / Tokens

Icon Notation Meaning Usage Note
1/2/3/4/5/6/7/8/9 Direction (numpad notation) Assuming you are on the left side. It can also be used as numbers inside the delay notation ("[]")
2(Charge) / 4(Charge) / 360 Charges / 360 (numpad notation) Assuming you are on the left side.
LP/MP/HP/LK/MK/HK/P/K Classic attack notation Used for attacks in Classic control.
L/M/H/Any/SP/Auto Modern attack notation Use for attacks in Modern control. The tool is planned to distinguishes the use of SP button and full command (for damage calculation, etc.).
Throw/DP/DI/DR/CR/Jump Common tokens Common notation tokens. The tool does not recognize regular inputs like LP+LK for throws.
Hold/Hold2/Hold3/Or Utility tokens Used for hold, holdLv2, holdLv3, and alternatives.
[ ]/F/Hit Specifier tokens Used for adding specifiers like delay frames and nth hit to cancel or number of hits.
BOMB Special tokens Used for indicating when explosions like Blanka's dolls and JP's Departure hit. Explosions triggered with a move like AKI's bloom and Baison's mine are already accounted for and do not need this.
> / >> / - Separation tokens Used for separating move parts or target combo inputs.

Command Structure

  • Use ">" between move parts that are cancel extensions.
  • Use ">>" between move parts that has gaps, or anything else that are not part of the "combo" like micro walks, set ups.
  • Use "-" for target combos or follow-up options.
  • Use consistent move notation for sorting, filtering, and icon conversion to work correctly.
  • Air routes should include jump notation while in air.

Examples

  • 2LK > 2LP > 236LK (basic grounded route)
  • Jump HK > DR > 2MP > 214MP Hold > SA3 (air starter into super)
  • DI > 214MP >> HP - HP > 236LP (Drive Impact to set up and to the main combo)
  • 2MP > CR > 2HP [1 Hit] > 236HK - HK > 2HP > CR [4F] > 2HP > 623HP (Combo that require specific hit counts and timing for the route to work)
